# 个人成功基线

通用战术知识只能说明大多数玩家通常应该怎么做。个人成功基线从同一玩家、同一场比赛的成功交火中，
为死亡交火检索同阵营、同点位的相似样本，让建议能够引用玩家自己已经完成过的有效处理。

## 相似度

候选必须阵营和点位完全相同，再比较：

- 交火距离；
- 谁先造成伤害；
- 附近队友补枪准备代理；
- 接触前生命值。

相似度低于 65 的样本不会输出；85 以上为高置信度对照。输出包含失败/成功回合与 Tick、差异因素、
以及从差异生成的确定性训练建议。

## 解释边界

- 成功样本不是因果证明，只是比通用模板更贴近玩家自身的可执行参考；
- 如果两次可观测条件几乎一致，系统会建议复查首发命中和准星落点，不会强行编造站位原因；
- 没有同阵营、同点位成功样本时不输出个人基线；
- 当前只在单场内检索，后续可扩展到同一 SteamID 的跨场成功样本库。
