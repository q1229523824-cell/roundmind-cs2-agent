# RoundMind CS2 Agent 用户使用手册

> 适用版本：v0.2.0 · Windows 10/11 x64 · 更新日期：2026-08-26

RoundMind 是一款 CS2 Demo 复盘工具。它会读取 `.dem` 比赛文件，自动找到本场玩家，生成数据摘要、关键回合证据、接战风险和训练建议。普通用户不需要安装 Python，也不需要 API Key。

## 1. 三分钟快速开始

1. 从官方发布页下载 `RoundMind-Local-Parser-win-x64.zip`：
   <https://github.com/q1229523824-cell/roundmind-cs2-agent/releases/tag/v0.2.0>
2. 右键 ZIP，选择“全部解压”。不要只把 EXE 单独拖出来。
3. 进入解压后的文件夹，双击 `RoundMind-Local-Parser.exe`。
4. 保持黑色程序窗口打开。浏览器会自动打开 RoundMind 网页并切换到“本地模式”。
5. 网页显示“本地解析器已连接”后，选择一个 `.dem` 文件。
6. 等待系统读取玩家名单，从下拉框中选择要复盘的人。
7. 等待分析完成，查看教练结论、证据卡片和训练建议。
8. 使用结束后关闭黑色窗口，或在窗口中按 `Ctrl+C`。

公开网页：<https://roundmind-cs2-agent.yangmiaomiao37.chatgpt.site/>

## 2. 使用前准备

### 2.1 系统要求

- Windows 10 或 Windows 11，64 位系统；
- 建议至少 4 GB 可用内存；
- 浏览器建议使用最新版 Chrome 或 Edge；
- Demo 最大 500 MB；
- 解压后请预留约 500 MB 磁盘空间；
- 本地解析主要消耗 CPU，配置越高速度越快。

### 2.2 Demo 在哪里

CS2 Demo 文件后缀为 `.dem`。如果是平台下载的录像，请先确认拿到的是解压后的 `.dem`，而不是网页链接、ZIP、视频或截图。

## 3. 安装与启动

### 3.1 下载正确文件

只从项目 GitHub Releases 页面下载。正确文件名是：

```text
RoundMind-Local-Parser-win-x64.zip
```

### 3.2 必须完整解压

程序采用“免安装文件夹”形式。EXE 旁边的 `_internal` 文件夹包含 Python 和解析组件，缺少它程序无法启动。

正确结构类似：

```text
RoundMind-Local-Parser/
├─ RoundMind-Local-Parser.exe
├─ README-WINDOWS.txt
└─ _internal/
```

不要直接在 ZIP 预览窗口里运行，也不要只发送一个 EXE 给朋友。应发送完整 ZIP。

### 3.3 Windows 提示“未知发布者”

当前版本尚未购买商业代码签名证书，因此 Windows SmartScreen 可能显示“未知发布者”。请先确认文件来自上述官方 GitHub Release；确认来源后，可在提示中选择“更多信息”，再选择“仍要运行”。

### 3.4 正常启动的标志

- 出现一个黑色程序窗口；
- 窗口显示本地地址 `http://127.0.0.1:8765`；
- 浏览器自动打开 RoundMind；
- 网页显示“本地解析器已连接”。

黑色窗口不是报错窗口，而是本地解析服务。分析期间不要关闭。

## 4. 完整复盘流程

### 第一步：上传 Demo

点击上传区域，选择 `.dem` 文件。本地模式下，浏览器只把文件交给当前电脑上的解析器，不会上传到 Render 云端。

页面可能依次显示：

```text
正在上传 Demo…
正在读取 Demo 中的玩家名单…
已找到 10 名玩家，请选择复盘对象。
服务器正在解析回合与玩家事件…
Demo 解析完成，临时文件已删除。
```

“正在上传”在本地模式中指浏览器向 `127.0.0.1` 传输，不代表上传互联网。

### 第二步：选择玩家

系统会从 Demo 中读取玩家昵称和 SteamID。正常 5v5 比赛通常会显示 10 名玩家。请选择你自己或想复盘的对象；SteamID 用于区分同名玩家。

### 第三步：等待解析

解析速度取决于 Demo 大小、回合数、CPU 和磁盘速度。大文件可能需要数分钟。请保持：

- 黑色窗口处于打开状态；
- 浏览器页面不要刷新；
- 电脑不要进入睡眠；
- 不要同时提交多个大 Demo。

### 第四步：阅读结果

建议按以下顺序阅读：

1. **比赛摘要**：比分、K/D/A、ADR、KAST 和回合数；
2. **教练结论**：本场最值得优先修正的问题；
3. **证据卡片**：结论对应的回合、事件和样本量；
4. **接战决策卡**：当时局势、候选动作和风险评分；
5. **训练重点**：下一场只跟踪一个可执行目标。

## 5. 如何理解分析结果

### 5.1 风险评分不是“死亡评分”

风险评分描述接战发生前的条件，例如人数、队友距离、闪光、烟雾、站位和补枪条件。它不是因为玩家最后死亡，就反推这次选择一定错误。

### 5.2 高、中、低置信度

- **高置信度**：样本较多、数据链完整、多个指标指向同一结论；
- **中置信度**：存在可用证据，但样本量或局势信息有限；
- **低置信度**：样本很少，或 Demo 无法完整还原某些信息，只适合作为观察方向。

低置信度不是“答案错了”，而是提醒你需要更多 Demo 或人工复核。

### 5.3 建议为什么有时相似

默认离线模式使用可解释规则、统计工具和 Dust2 知识库生成建议。若多场比赛暴露相同问题，训练建议会保持一致，这是为了避免只换说法却不解决核心问题。连续分析同一 SteamID 的多场 Demo 后，玩家画像会更稳定。

## 6. 本地模式、云端模式与大模型

### 6.1 推荐使用本地模式

本地模式适合 100–500 MB Demo：

- 不受家庭网络上传速度影响；
- 原始 Demo 不离开电脑；
- 解析完成后删除临时副本；
- 不需要安装 Python；
- 不需要 API Key。

### 6.2 默认没有调用大模型

Demo 解析、指标计算、风险评分和基础建议都能离线运行。程序不是在本地部署了一个大模型，而是用确定性解析器、工作流、规则和知识库生成可验证结论。

如需更自然、更个性化的追问，可让每位用户使用自己的 DeepSeek API Key：

1. 双击发布包中的 `Start-RoundMind-With-DeepSeek.cmd`；
2. 阅读数据说明，输入大写 `YES` 表示同意；
3. 输入自己的 DeepSeek API Key，输入内容不会显示；
4. 浏览器打开后照常上传 Demo、选择玩家并追问。

密钥只保存在本次本地程序进程中，关闭黑色窗口后失效，不会写入网页、GitHub、配置文件或作者服务器。调用 DeepSeek 时，只发送匿名化教练上下文、当前问题和最近最多 12 条对话；不会发送原始 Demo、文件路径、SteamID 或玩家昵称。产生的 API 费用由密钥所有者承担。

## 7. 常见问题排查

### 7.1 双击后没有任何反应

1. 确认已经完整解压；
2. 确认 `_internal` 与 EXE 在同一文件夹；
3. 不要在 ZIP 内直接双击；
4. 查看 Windows 安全中心是否隔离了文件；
5. 将报错窗口截图发给项目维护者。

### 7.2 网页显示“未连接本地解析器”

1. 确认黑色窗口仍然打开；
2. 刷新网页，等待 3–5 秒；
3. 临时关闭会拦截本机网页连接的浏览器扩展；
4. 改用后端自带页面：

```powershell
.\RoundMind-Local-Parser.exe --local-ui
```

### 7.3 提示端口 8765 被占用

关闭旧的 RoundMind 窗口，或者使用另一个端口和本地页面：

```powershell
.\RoundMind-Local-Parser.exe --port 8766 --local-ui
```

### 7.4 找不到玩家或玩家数量异常

- 确认文件是完整比赛 Demo，而不是损坏或未下载完成的文件；
- 热身、观战者、替补或特殊模式可能让人数不是正好 10；
- 新版本 CS2 可能改变 Demo 格式，需要更新解析器；
- 可先运行兼容性检查：

```powershell
.\RoundMind-Local-Parser.exe --check-demo "D:\Demo\match.dem"
```

### 7.5 一直停在解析中

大 Demo 在低配置电脑上可能需要数分钟。如果超过 10 分钟：

1. 记录 Demo 大小；
2. 截图网页状态和黑色窗口最后 20 行；
3. 不要发送 API Key、Steam 登录信息或私人路径；
4. 关闭程序后重启，再单独分析这一份 Demo。

### 7.6 显示 Demo 超过 500 MB

当前单文件上限是 500 MB。不要通过改后缀或截断文件绕过限制；应换用体积较小的完整 Demo，或联系维护者评估提高上限。

### 7.7 中文显示为问号

这通常是英文 Windows 控制台的字符集限制，不影响解析结果。网页报告仍应正常显示中文。

## 8. 隐私与安全

- 本地服务只监听 `127.0.0.1`，同一局域网的其他电脑不能直接访问；
- 原始 Demo 在本地解析，不上传到 Render；
- 临时 Demo 在成功、失败或取消后都会清理；
- 默认不调用外部大模型；
- 报告可能包含玩家昵称、SteamID 和比赛表现，转发前请自行确认是否需要遮挡；
- 不要把 API Key、Steam 密码、验证码或 `.env` 文件发给任何人。

## 9. 向维护者反馈问题

为了快速定位问题，请提供：

```text
RoundMind 版本：v0.2.0
Windows 版本：
浏览器：
Demo 大小：
问题发生步骤：
网页提示：
黑色窗口最后 20 行：
是否可以稳定复现：
```

如果 Demo 可以公开，可另行提供；如果不能公开，只发送上述信息即可。请勿发送 API Key、密码或其他账号凭据。
