# 大模型教练上下文包

`coach_context.py` 负责把确定性事实组合成大模型可消费的有界 JSON，但不会调用任何外部模型。
这样可以独立评测“上下文是否正确”和“模型是否正确使用上下文”。

## 内容

- 数据质量、场数、回合数、交火数和画像置信度；
- 武器分布与角色倾向；
- 跨场重复发现和被先手伤害切片；
- 最多 4 个代表失败案例，以及能够检索到时的个人相似成功案例；
- 最多 3 条 Dust2 战术知识；
- 最多 3 个带指标的训练重点；
- 最多 6 个不泄漏结果的交火候选动作比较；
- 限制模型表述边界的 `response_guardrails`。

## 隐私与边界

上下文不会包含昵称、SteamID、原始 `match_id`、Demo 文件名或本地路径。玩家只使用不可逆摘要生成的
`player_ref`，比赛使用当前包内的 `match_01` 等临时编号。整个 JSON 最大 32 KB；当前三场真实数据生成的
上下文约 11 KB，远小于原始 Demo。

质量门禁失败的比赛不会进入证据选择。低置信度切片可以进入包中供模型解释不确定性，但不能被表述为
稳定弱点。知识条目和个人案例必须保留 ID、回合与样本量，模型不得编造包外事实。

## 本地运行

```powershell
python -m chapter07_cs2_coach.context_cli `
  --demo-dir ".agent_data\demos" `
  --player-steamid "7656..." `
  --map-name de_dust2 `
  --output ".agent_data\contexts\dust2-context.json"
```

下一阶段接入模型时，只发送该 JSON 和用户当前问题，不发送原始 Demo。模型输出还需要经过证据引用与
幻觉检查，不能因为语言更自然就跳过评测。
